# SEET paper split: unrecovered

The 3ET paper reports that 22 of the 66 LPW recordings were selected because
their eye movements had above-average speed, and that the data were allocated
80/20 for training and validation. The surviving public artifacts do not
establish the exact 22 recording IDs, the allocation unit or procedure, or the
calculation used for eye-movement speed.

This directory intentionally contains no `train_files.txt` or `val_files.txt`.
Publishing a guessed list would create false provenance. If the original lists
are recovered, add a new immutable split version rather than changing
`SEET-public-v1`.
